Press **Ctrl+K** (⌘K on macOS) and type part of a command name, a file name in the active panel, or a full folder
path, then press **Enter**. Each command shows its shortcut, so the palette also helps you learn the keys.

Commands without a key, such as Search files, Synchronize directories or Check for updates, are always in the
palette. [Keyboard shortcuts](../shortcuts.md) has the full list.
